# Qian Ma Academic Homepage

Personal academic homepage for Qian Ma, built with HugoBlox Kit and the Academic CV template.

## Local Development

Install dependencies:

```bash
corepack enable
pnpm install
```

Run the site locally:

```bash
pnpm run dev
```

Build the production site:

```bash
pnpm run build
```

The project expects Hugo Extended `0.163.3` or newer.
